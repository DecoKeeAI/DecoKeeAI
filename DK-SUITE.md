# DK-Suite

DK-Suite is the official software for DECOKEE Quake.

DK-Suite is developed and maintained separately from the open-source DecoKeeAI concept project.

Official DK-Suite installers may be distributed through the Releases section of this repository.

The DK-Suite source code is not published in this repository. The open-source DecoKeeAI codebase is an early experimental concept project from 2024 and does not represent the current DK-Suite codebase.

DK-Suite is currently closed-source to ensure product stability, hardware compatibility, software security, and reliable customer support.

Third-party forks, plugins, scripts, or projects based on DecoKeeAI are independent community projects unless explicitly announced by DECOKEE.
